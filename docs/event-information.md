# NASA data requirements and judging criteria

## Selected challenge

[Be an Earth System Trend Detective!](https://www.spaceappschallenge.org/2026/challenges/earth-system-trend-detective/)

## NASA data and prototype requirements

- At least one NASA dataset is mandatory for Global Awards eligibility.
- Satellite imagery, CSV/JSON files, processed datasets, charts and other NASA
  data resources can be used. A live NASA API connection is not required.
- Other datasets may complement NASA data.
- Name the NASA datasets, link their sources and explain how they support the
  solution. Meaningful use of NASA data must be demonstrated.
- A fully functional application is not required: a well-presented concept or
  prototype demonstrating meaningful NASA data usage is acceptable.
- Review the selected challenge's objectives and Resources tab for any specific
  dataset requirements.

## Judging criteria

Each criterion is scored from 1 to 5.

| Criterion | What judges assess |
| --- | --- |
| Impact | What problem is solved and why it matters |
| Creativity | Innovation or originality of the approach |
| Validity | Support from relevant evidence and appropriate data |
| Relevance | How well the solution addresses the selected challenge |
| Presentation | Clarity and effectiveness of communication |
