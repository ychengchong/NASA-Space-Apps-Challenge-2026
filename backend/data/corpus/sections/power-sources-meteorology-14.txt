POWER Meteorological Data Sources: Corrected Wind Speed
Publisher: NASA Langley Research Center, POWER Project

In addition to the wind speed parameters available at set heights above surface, the POWER API allows the user to request a wind speed at a user defined height (between 10 and 300 m) for a particular surface type. The height adjustment applies a surface-roughness power-law (Hellmann/power-law profile), a widely used engineering approximation for the near-surface wind profile under neutral stability (Peterson, 1978).

Equation: Corrected Wind Speed (Adjusted for Elevation)

\begin{align}\ WSC_{hgt} = WS_{50m} \times \left(\frac{hgt}{50. }\right) ^{\alpha} \end{align}

\begin{align} Where&: \\ &WSC_{hgt} : \text{ Corrected wind speed at user supplied height and surface type} \\ &hgt : \text{ User supplied height above surface in meters} \\ &WS_{50m} : \text{ Wind speed at 50 meters } \\ &\alpha: \text{ Surface roughness for user supplied surface type } \\ \end{align}
