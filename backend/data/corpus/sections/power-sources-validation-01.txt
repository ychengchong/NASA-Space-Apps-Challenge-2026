POWER Validation Data Sources: Validation Sources
Publisher: NASA Langley Research Center, POWER Project

In addition to the core data products, POWER curates and provides several point-based in-situ validation data sets for the express purpose of validating POWER data. These are the same data sets that the POWER team use to validate a subset of the core data sets that are detailed within the methodology pages. They are not made available to validate derived parameters.

They are available for the public in the Data Access Viewer and through an API endpoint for specific parameters.

The sources below have been vetted for quality of the data and availability for global and temporal coverage.
